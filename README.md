# AROUND Magazine Clone

React를 활용해 AROUND 매거진의 메인 페이지와 기사 상세 페이지를 구현한 클론 프로젝트입니다.

단순히 화면을 비슷하게 만드는 데 그치지 않고,  
기사마다 서로 다른 본문 구조를 데이터로 정리하고 하나의 공통 컴포넌트에서 렌더링할 수 있도록 설계했습니다.

또한 동적 라우팅, 반응형 UI, 메뉴 및 슬라이더 인터랙션을 구현하고 GitHub Pages를 통해 실제 웹사이트로 배포했습니다.

## 프로젝트 개요

- 프로젝트 유형: 개인 프로젝트
- 개발 환경: React 18, Vite 5
- 주요 구현 범위:
  - 메인 페이지
  - 기사 상세 페이지
  - 동적 라우팅
  - 반응형 레이아웃
  - 드로어 메뉴
  - 자동 슬라이더
  - 구독 유도 UI
  - GitHub Pages 배포
